# Портфолио

Живой сайт: **https://n4448233-cmyk.github.io**

Простой сайт-портфолио без фреймворков: чистые HTML, CSS и JavaScript.
Работает без сборки и установки чего-либо — открой и пользуйся.

## Что где лежит

```
index.html      — сама страница (тексты приветствия и «обо мне» правятся тут)
css/style.css   — все стили, палитра и шрифты настраиваются в начале файла
js/data.js      — твоё имя, контакты и список проектов
js/main.js      — логика страницы (галереи, просмотр скриншотов), трогать не нужно
img/projects/   — скриншоты проектов
favicon.svg     — иконка сайта во вкладке
```

## Как посмотреть у себя

Просто открой `index.html` двойным кликом — всё заработает.
Если хочешь «как на сервере», из этой папки можно запустить:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Как добавить проект

1. Открой `js/data.js`
2. Скопируй любой объект `{ ... }` из списка `PROJECTS`, вставь его туда же
3. Поменяй поля: название, описание, теги, ссылки `demo` / `source`
4. Сохрани файл, обнови страницу

У первого проекта с полем `featured: true` карточка растягивается
на всю ширину — можно оставить это у самого крутого проекта.

## Скриншоты проекта (галерея)

У проекта есть поле `images` — список путей к картинкам:

- **Несколько картинок** — в карточке появляется листалка (свайп на телефоне,
  стрелки при наведении на компе, точки внизу). Клик по скриншоту открывает
  большой просмотр: там листание стрелками клавиатуры, кнопка «Открыть сайт»,
  закрытие по Esc или клику мимо картинки.
- **Одна картинка** — показывается без стрелок, по клику тот же большой просмотр.
- **Пустой список `[]`** — вместо картинки будет аккуратная заглушка с номером.

Как положить свои скриншоты:

1. Сделай скриншоты сайта (Win + Shift + S, или весь экран через F11)
2. Сохрани их в `img/projects/` с понятными именами: `vizitka-1.png`, `vizitka-2.png`…
3. Впиши пути в поле `images` проекта в `js/data.js`:
   `"img/projects/vizitka-1.png"`

Совет: держи один размер (например, 1600×1000) и формат JPG или WebP —
страница будет открываться быстрее. Файлы-заглушки `*.svg` из `img/projects/`
можно удалить, когда везде будут стоять настоящие скриншоты.

## Как поменять имя и контакты

В начале `js/data.js`:

- `PROFILE.name` — имя (в шапке, приветствии и подвале)
- `CONTACTS.email` — почта (кнопка «скопировать» подхватит её сама)
- `CONTACTS.socials` — ссылки: GitHub, Telegram и что захочешь

Тексты приветствия и раздела «Обо мне» лежат прямо в `index.html` —
найди их по комментариям `<!-- -->` и перепиши своими словами.

## Как выложить в интернет (бесплатно)

### Вариант 1: GitHub Pages (основной)

1. Заведи аккаунт на [github.com](https://github.com), если его ещё нет
2. Создай новый репозиторий с именем `<твой-ник>.github.io` — тогда сайт
   будет доступен прямо по этому адресу (или любое другое имя — сайт будет
   по адресу `<твой-ник>.github.io/<имя-репозитория>`)
3. Загрузи туда все файлы из этой папки (через веб-интерфейс или git)
4. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch →
   main / root → Save**
5. Через минуту-две сайт откроется по твоей ссылке — её уже можно кидать кому угодно

### Вариант 2: Netlify Drop (совсем без git)

1. Зайди на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащи туда эту папку целиком
3. Получишь ссылку, можно потом поменять на свою поддомен-имя

## Как поменять цвета

В начале `css/style.css` есть блок `:root` — там пять переменных:

```css
--bg: #131312;       /* фон */
--bg-soft: #1b1b19;  /* фон карточек */
--ink: #ebe9e4;      /* текст */
--muted: #a3a09a;    /* приглушённый текст */
--accent: #ff5d3b;   /* акцент */
```

Поменяй значения — весь сайт перекрасится автоматически.
